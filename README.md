# 🤖 AI Business Assistant

AI Business Assistant is a multi-agent business analysis application
built with Streamlit and CrewAI.

## Features

- Business analysis
- Problem diagnosis
- Business strategy recommendations
- Marketing strategy
- Content generation
- Action planning
- Final business report
- Downloadable report

## AI Agents

1. Business Analyst
2. Problem Diagnosis Agent
3. Strategy Agent
4. Marketing Agent
5. Content Agent
6. Action Planner
7. Business Manager

## Project Structure

ai-business-assistant/

├── app.py
├── agents.py
├── requirements.txt
└── README.md

## Installation

Install the dependencies:

pip install -r requirements.txt

## Run

streamlit run app.py

## API Key

The application asks for the Groq API key through the Streamlit
interface.

No .env file is required.

## Workflow

User Business Information
        ↓
Business Analyst
        ↓
Problem Diagnosis
        ↓
Strategy Agent
        ↓
Marketing Agent
        ↓
Content Agent
        ↓
Action Planner
        ↓
Business Manager
        ↓
Final Business Report
